# Query budget from the lattice count, support grid excluded, k-nearest estimator primary

The query budget N is defined as the number of lattice-baseline points that fall inside the sampling region of the eroded mask (specimen mask eroded by a fixed 4 tracker-input px, the same rule on every dataset) at a chosen spacing, and the adaptive method must spend exactly that many distinct query points across its coarse pass and refinement points. The tracker's support grid is pinned identical across methods, excluded from N, and reported. Re-tracked points count once. Both methods report strain only from one measurement pass of all N points together; the adaptive method's coarse pass only guides placement, and its extra tracking run is reported as compute, not hidden in the budget. This keeps the comparison at one N-point tracking run per method, since a tracker's output for a point can depend on which other points it tracks alongside. Counting N in the eroded mask, and scoring only the eroded gauge section, keeps the budget equal to what either method can actually place and avoids grading extrapolation at edges neither may sample. We chose this over a free "N points" parameter so that every budget corresponds to a real, reproducible lattice with no rounding games, and so that tracker compute (support grid, re-tracking) cannot be confused with placement.

The pre-registered primary strain estimator is the k-nearest local affine fit, with k tied to a fixed radius of 2.5 baseline spacings at baseline density. The fixed-radius fit is the conservative secondary; both are reported. With a fixed radius, extra points only reduce variance at a smoothing width set by the baseline, so narrow bands are blurred identically for both methods; since the project claims resolution of narrow bands, the primary must let added density sharpen the fit. Tying k to the radius makes the two estimators coincide on the baseline, so any k-nearest gain is attributable to placement.

## Considered Options

- Fixed-radius primary: rejected because it caps the adaptive method at variance gains and cannot test the resolution claim.
- Budget as a free point count with farthest-point sampling: rejected because the research question promises an equally budgeted lattice, and DIC readers expect one.
