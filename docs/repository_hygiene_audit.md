The offline tracking figure now includes the synthetic credit in a visible
`figcaption` beside the canvas, so attribution travels with the HTML. Its frames
come directly from the synthetic experiment result. The generator's version,
content hash, and frame hash remain in the associated run record.

Real-data loading and figures are future work at this revision. Keep their source
data outside the checkout and their masks, tracks, hand annotations, and results
out of Git. Before publishing any external-data figure or derivative, verify
redistribution permission and put the dataset name, creator/source, and required
license/attribution in its rendered caption. Retain that caption in screenshots
and video. A credit alone does not establish redistribution permission.

The ignore rules now also cover environment-file variants, private-key files,
common dataset/derivative formats, standalone images/videos, and SQLite results.
They prevent routine accidental additions; `git add -f` bypasses them and already
tracked files are unaffected. Review staged paths before each commit.

## Repeat the audit

Use a complete checkout and Gitleaks 8.30.1 on `PATH`. Run from the repository root.
Store inventories, extracted blobs, and redacted scan reports outside the checkout:

```bash
git fetch --tags origin
git rev-parse HEAD
git rev-parse --is-shallow-repository  # must be false
git ls-remote --heads --tags origin
git for-each-ref --format='%(refname) %(objectname)'
git lfs ls-files --all
export STRAINSIGHT_AUDIT_DIR="$(mktemp -d)"
python3 - <<'PY'
from collections import Counter
from pathlib import Path
import os
import subprocess

def git(*args):
    return subprocess.check_output(["git", *args])

root = Path(os.environ["STRAINSIGHT_AUDIT_DIR"])
blobs = root / "blobs"
blobs.mkdir()
commits = git("rev-list", "--all").decode().splitlines()
paths, objects, modes = set(), set(), set()
for commit in commits:
    for entry in git("ls-tree", "-r", "-z", commit).split(b"\0"):
        if not entry:
            continue
        metadata, path = entry.split(b"\t", 1)
        mode, kind, oid = metadata.decode().split()
        paths.add(path.decode())
        modes.add(mode)
        if kind == "blob":
            objects.add(oid)
size = 0
for oid in sorted(objects):
    content = git("cat-file", "blob", oid)
    (blobs / oid).write_bytes(content)
    size += len(content)
    try:
        content.decode("utf-8")
        assert b"\0" not in content
    except (UnicodeDecodeError, AssertionError):
        print("REVIEW binary blob:", oid)
(root / "paths.txt").write_text("\n".join(sorted(paths)) + "\n")
print("commits, paths, blobs, bytes:", len(commits), len(paths), len(objects), size)
print("file modes:", sorted(modes))
print("extensions:", Counter(Path(p).suffix or "(none)" for p in paths))
PY
gitleaks git . --log-opts='--all --full-history' --redact=100 \
  --max-decode-depth=3 --max-archive-depth=3 \
  --report-format=json --report-path="$STRAINSIGHT_AUDIT_DIR/history-secrets.json"
gitleaks dir "$STRAINSIGHT_AUDIT_DIR/blobs" --redact=100 \
  --max-decode-depth=3 --max-archive-depth=3 \
  --report-format=json --report-path="$STRAINSIGHT_AUDIT_DIR/blob-secrets.json"
git log --all --format=fuller > "$STRAINSIGHT_AUDIT_DIR/commit-metadata.txt"
gitleaks dir "$STRAINSIGHT_AUDIT_DIR/commit-metadata.txt" --redact=100 \
  --max-decode-depth=3 \
  --report-format=json --report-path="$STRAINSIGHT_AUDIT_DIR/metadata-secrets.json"
```

Read every historical path in `paths.txt`; inspect suspect blobs with
`git cat-file blob <object-id>` and find their paths with
`git log --all --find-object=<object-id> --name-only`. Review text formats too:
masks, tracks, annotations, and embedded/base64 images can be text. Inspect all
new or changed files with `git diff --cached` before committing. Scan those files
with `gitleaks dir` as well, or rerun the history scan after committing.

If a check finds actual data or a secret, deletion from the current tree is
insufficient: stop publication, remove it from every affected ref, and rotate any
exposed credential before repeating the audit. Record the final revision, counts,
scan results, and figure credits here when repeating the submission audit.
